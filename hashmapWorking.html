Load factor → determines when resizing should happen. Threshold → capacity × load factor. Resize → usually doubles capacity. Treeification → happens when a bucket becomes sufficiently crowded (~8 nodes) and capacity ≥ 64. If bucket reaches ~8 nodes but capacity < 64, HashMap prefers resizing instead of treeifying. Treeification changes the bucket from a linked list → Red-Black Tree. Tree can later convert back to a linked list when it becomes small enough (~6 nodes).
